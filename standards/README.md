# Standards

Framework-independent principles, loaded only when relevant to a task. Project-specific decisions remain in the consumer's documents.

| Standard | Read when |
|---|---|
| [Web security](web-security.md) | Changing identity, ownership, input, storage or network boundaries |
| [Dependencies](dependencies.md) | Adding, updating or auditing packages |
| [Testing](testing.md) | Designing tests and verification gates |
| [Privacy](privacy.md) | Changing personal-data collection, use or retention |

These standards are available as repository content following Issue #3. Package lookup ships in #5 and consumer test/CI templates in #6. Role-based workflow follows in #7. Legacy documents are migration references, not a second source for new-core policy.
